# منظم حياتي (Life Organizer)

تطبيق React شخصي لتنظيم الوقت: الرئيسية، الجيم (تدريب/وقت/مكملات/طعام)، اللغة، الأنشطة (مع كشف تعارض الأوقات وتنبيهات قابلة للتخصيص)، والإعدادات.

## التشغيل محلياً

```bash
npm install
npm run dev
```

بيفتح على `http://localhost:5173`

## البناء للنشر

```bash
npm run build
```

بينتج مجلد `dist/` جاهز للرفع على أي استضافة ستاتيك (GitHub Pages, Vercel, Netlify...).

## رفع التحديثات على GitHub

```bash
git add -A
git commit -m "وصف التحديث"
git push
```

## ملاحظة عن التخزين

النسخة هاي بتستخدم `localStorage` بالمتصفح لحفظ بياناتك. هاد يعني البيانات بتضل محفوظة بنفس المتصفح والجهاز بس - لما نضيف ميزة المشاركة مع صديق مستقبلاً، رح نحتاج قاعدة بيانات وباك اند حقيقي.

## ملاحظة عن التنبيهات

التنبيهات الفعلية (push notifications حقيقية على الجهاز) بتحتاج صلاحيات متصفح/جهاز حقيقية غير متوفرة بهاي النسخة. المنطق والواجهة جاهزين (وقت التنبيه لكل نشاط، كشف تعارض الأوقات)، وربطهم بتنبيهات فعلية بيصير بمرحلة النشر الحقيقي.
